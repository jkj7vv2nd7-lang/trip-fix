# TripFix

採点済みの答案を写真で記録し、間違えた原因を分析して、解説・補強プリント・解き直しの循環で「同じミスを繰り返さない」ことを目指す、中高生向けの学習アプリです。

**公開ページ：** https://jkj7vv2nd7-lang.github.io/trip-fix/

## 特徴

- 答案の写真と記録は、**端末の中にだけ**保存されます（サーバーに送られません）
- 問題ごとに ○×△・配点・単元・間違えた原因タグを付けて記録できます
- 写真にはマスキング（名前などを黒く塗る）・切り抜き・回転ができます
- 補強プリントの問題は、アプリが新しく作るオリジナル問題だけです（撮影した問題そのものは載せません）

## 開発状況

- フェーズ1（土台と記録）：完了 ― 撮影・記録・確認・修正・保存・設定・容量管理
- フェーズ2（分析・解説・読み上げ）、フェーズ3（補強プリント・解き直し）、フェーズ4（任意AIモード）：実装済み
- AIモードは任意・初期設定オフです。使う場合だけ、自分のAPIキーで写真の下書き読み取りと解説の下書きが使えます（下書きは必ず本人が確認してから取り込みます）
